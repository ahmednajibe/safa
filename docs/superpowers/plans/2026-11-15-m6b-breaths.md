**Why:** The user asked what happens with deep breaths between sentences, and confirmed their 3 real recordings contain breaths. Orchestrator probe finding: Silero VAD folds most of these breaths **into speech segments** (only 2 soft breath candidates were found in VAD gaps, in `Recording.m4a` at 12.60–12.76 s and 24.50–24.80 s), so Cut silence alone cannot handle them — detection must be frame-level, inside speech segments too.

**Goal:** A new op `breaths` ("Reduce breaths") that attenuates breaths (default −12 dB) with smooth envelopes and never touches /s f h sh/ or soft word starts; plus the silence padding bug fix.

## Global Constraints
- Attenuate, never delete: default 12 dB (range 6–20), and never below `floor_dbfs + 2 dB` (use `level_stats`).
- Gain envelope at 10 ms hop: 20 ms raised-cosine attack, hold, 35 ms release (15 ms when a voiced onset follows within 60 ms).
- CPU only, numpy/scipy + silero-vad; < 0.5 s processing per minute of audio; streaming/chunked with context for long files.
- All summaries via `msg()`: `breaths_reduced{count, db}`.

## Review Focus
1. Consonant safety: SAPI passage "She sells five fast horses. Happy home, fresh fish, soft shoes." (no breaths) → 0 detections, and RMS + 4–10 kHz band change < 0.2 dB in every `[onset−50 ms, onset+150 ms]` window (test).
2. Synthetic breaths (Argon §4 recipe: white noise → band-pass 400–4200 Hz + formant peaks ~750/1750 Hz Q 2 +6 dB, Beta(2,2) envelope 350 ms at −24 dBFS) inserted 40 ms before SAPI word onsets and inside 0.35 s pauses → each attenuated 12 ± 2.5 dB; speech RMS change ≤ 0.1 dB; no boundary clicks (test).
3. Real recordings: inter-phrase non-speech P90 RMS drops ≥ 6 dB vs the same chain without breaths; whisper transcript unchanged (slow test); report detections per recording with timestamps (must include the two probe candidates in `Recording.m4a` or explain).
4. Breath detected right before a word whose first sound is /h/ ("happy") → the 45 ms pre-voicing collar keeps the /h/ intact (test on synthetic).
5. Silence padding fix: a raw VAD gap of 0.4 s with `min_silence_s=0.3` IS cut (today it is kept because padding is applied before the check) (test).

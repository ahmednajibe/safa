# M2 — App Shell Implementation Plan

> **For agentic workers:** Implement task-by-task, test-first. Do NOT commit. Read `AGENTS.md`, `docs/SPEC.md` (§4, §5, §8), `docs/UI_DESIGN.md`, `docs/FEASIBILITY.md` first.

**Goal:** One command (`start.bat`) starts a local FastAPI server on 127.0.0.1:8790 that serves the built React app and answers `/api/health` and `/api/operations`; the page shows the empty workbench shell with real health info and the operation list.

**Architecture:** FastAPI app factory in `backend/main.py`; SQLite schema created at startup; operation registry is pure data + conflict resolver (no processing yet); capabilities detected cheaply (no torch import in the API process); React + Vite + TS + Tailwind v4 app in `frontend/`, built to `frontend/dist` and mounted by FastAPI with SPA fallback.

**Tech Stack:** FastAPI, uvicorn, sqlite3 (stdlib), pytest + httpx TestClient; Vite 6, React 18, TypeScript, Tailwind v4 (`@tailwindcss/vite`), `@fontsource/inter`.

**Spec:** `docs/SPEC.md`, `docs/UI_DESIGN.md`

## Global Constraints
- Bind `127.0.0.1` only, port `8790`.
- API process must not import torch / onnxruntime / ctranslate2 / df / audio_separator (startup must stay < 3 s). Use `importlib.util.find_spec` and files on disk.
- Fix from M1 review: `configure_model_env()` must **assign** (not `setdefault`) HF_HOME/HF_HUB_CACHE/TORCH_HOME/XDG_CACHE_HOME so a global user env var can't send downloads to the user profile. Add a test.
- UI tokens/type exactly from `docs/UI_DESIGN.md` §3–§4; Inter from `@fontsource/inter` (no Google Fonts link — offline). Dark only. No gradients/shadows-at-rest/monospace/uppercase labels.
- Op names/descriptions exactly from `docs/UI_DESIGN.md` §7.
- All paths via `backend/core/paths.py`.

## Review Focus
1. Server started from a different cwd (e.g. `C:\`) still finds `frontend/dist`, `data/`, `tools/` → all via `paths.ROOT` (test with `monkeypatch.chdir(tmp_path)`).
2. `frontend/dist` missing → `/` returns a 200 plain HTML page saying "Frontend not built — run scripts/setup.ps1", API still works (test).
3. Unknown SPA route `/history` → serves `index.html`; unknown `/api/nope` → JSON 404, not index.html (test).
4. A model file missing on disk → that op `available: false` with reason `"model_missing"`, others unaffected (test with monkeypatched MODELS_DIR).
5. Selecting Karaoke + denoise + enhance + silence(mode=vad) → those three listed in `disabled` with human reasons; silence(mode=amplitude) stays enabled (test).

### Task 1: Settings, DB, app factory
**Files:** Create `backend/core/settings.py`, `backend/db.py`, `backend/main.py`, `tests/test_app.py`; modify `backend/core/models_manifest.py`, `tests/test_core.py`.

**Interfaces — Produces:**
- `settings.py`: `@dataclass Settings(host="127.0.0.1", port=8790, data_dir=DATA_DIR, db_path=DATA_DIR/"app.db", retention_days=7, max_upload_mb=4096)`; `get_settings() -> Settings` (cached).
- `db.py`: `connect(db_path: Path) -> sqlite3.Connection` (row_factory=Row, WAL, foreign_keys on); `init_db(db_path: Path) -> None` creating:
  - `media(id TEXT PK, filename TEXT, stored_path TEXT, size_bytes INT, probe_json TEXT, created_at TEXT)`
  - `jobs(id TEXT PK, media_id TEXT REFERENCES media(id), kind TEXT CHECK(kind IN ('full','preview')), ops_json TEXT, output_json TEXT, preview_json TEXT, state TEXT CHECK(state IN ('queued','running','completed','failed','cancelled','interrupted')), stage TEXT, stage_idx INT, total_stages INT, stage_pct REAL, overall_pct REAL, eta_sec REAL, device TEXT, message TEXT, error TEXT, worker_pid INT, created_at TEXT, started_at TEXT, finished_at TEXT)`
  - `job_files(job_id TEXT REFERENCES jobs(id), name TEXT, kind TEXT, path TEXT, size_bytes INT, PRIMARY KEY(job_id,name))`
- `main.py`: `create_app(settings: Settings | None = None) -> FastAPI` (runs `init_db`, includes routers, mounts SPA); module-level `app = create_app()`.
- Tests: `test_init_db_creates_tables` (3 tables exist), `test_init_db_idempotent`, `test_configure_model_env_overrides_existing` (set `HF_HOME=C:\elsewhere` via monkeypatch → after call it is under MODELS_DIR).

### Task 3: Operation registry, presets, conflicts, `/api/operations`
**Files:** Create `backend/operations/__init__.py`, `backend/operations/registry.py`, `backend/operations/rules.py`, `backend/api/operations.py`; tests `tests/test_operations.py`.

**Interfaces — Produces:**
- `registry.py`:
  - `@dataclass ParamSpec(key: str, label: str, type: Literal["number","select","bool"], default: Any, min: float|None=None, max: float|None=None, step: float|None=None, unit: str|None=None, options: list[dict]|None=None, advanced: bool=False, help: str|None=None)` (`options` items `{"value","label"}`).
  - `@dataclass OpSpec(id: str, order: int, name: str, description: str, engine: str, device: Literal["cpu","gpu","gpu-optional"], params: list[ParamSpec], changes_timeline: bool, requires_modules: list[str], requires_models: list[str], planned: bool=False)`.
  - `OPERATIONS: dict[str, OpSpec]` — all 14 ops from SPEC §2 with `order`, UI_DESIGN §7 names/descriptions, and params:
    - trim: start_s (number, 0, unit s), end_s (number, null = end) · changes_timeline
    - channel: mode select keep|mono|left|right (default keep)
    - highpass: cutoff_hz number 75 (40–200)
    - dehum: base select 50|60 (default 50), harmonics number 4 (1–8, advanced)
    - separate: output select vocals|instrumental|both (labels "Keep voice", "Keep music (karaoke)", "Export both"), model select htdemucs|kim_vocal_2 (advanced) · requires audio_separator + model htdemucs
    - dereverb: strength number (advanced) · `planned=True` until M7 proves a model
    - denoise: engine select ai|classic (labels "AI (DeepFilterNet)", "Classic"), strength_db number 24 (6–40, unit dB) · requires df + deepfilternet3 for ai
    - declick: sensitivity select gentle|normal|strong
    - enhance: preset select voice|bright|warm, deess bool true
    - enhance_ai: `planned=True`
    - silence: mode select vad|amplitude (labels "Speech detection", "Volume threshold"), max_pause_s 0.6, keep_pause_s 0.25, pad_s 0.2 (advanced), threshold_db -40 (advanced, amplitude mode) · changes_timeline
    - speed: factor number 1.0 (0.5–2.0, step 0.05) · changes_timeline
    - loudness: target select podcast|youtube|custom (−16 / −14 / custom), lufs number −16 (advanced), true_peak_db −1 (advanced)
    - subtitles: language select auto|en|ar|…(a short list), format select srt|vtt|both
  - `ops_in_order() -> list[OpSpec]`.
  - `PRESETS: dict[str, dict]` → `{"podcast": {"name":"Podcast cleanup","ops":{"highpass":{},"denoise":{},"enhance":{},"silence":{"mode":"vad"},"loudness":{"target":"podcast"}}}, "remove_music": {...separate vocals, denoise, loudness}, "echoey_room": {...dereverb, denoise, enhance, loudness}, "lecture": {...highpass, dehum, denoise, silence, loudness, subtitles}, "karaoke": {...separate instrumental, loudness youtube}, "jump_cut": {...denoise, silence vad, loudness youtube}}` — ops values are param overrides.
- `rules.py`: `@dataclass Effective(ops: list[tuple[str, dict]], disabled: dict[str, str])`; `resolve(selection: dict[str, dict], available: dict[str, bool]) -> Effective` — fills defaults, validates params (raise `ValueError` with message on unknown op/param/out-of-range), sorts by `order`, applies rules: separate.output=="instrumental" disables denoise, enhance, silence(mode vad) with reason "Off while Karaoke is on: noise reduction works on speech." (wording per op); unavailable/planned ops go to `disabled` with reason `"Not available on this computer"` / `"Model not downloaded yet"` / `"Coming later"`.
- `GET /api/operations` → `{"operations":[{…OpSpec, "available": bool, "unavailable_reason": str|null}], "presets": {...}}` in order.
- `POST /api/operations/resolve` body `{"ops": {id: params}}` → `{"ops":[{"id","params"}], "disabled": {id: reason}}`; 422 on ValueError with message.
- Tests: `test_fourteen_ops_in_order`, `test_names_match_ui_design` (spot-check 4 names), `test_presets_reference_valid_ops_and_params`, `test_karaoke_conflicts` (Review Focus 5), `test_resolve_rejects_out_of_range` (speed factor 3 → 422), `test_model_missing_marks_unavailable` (Review Focus 4).

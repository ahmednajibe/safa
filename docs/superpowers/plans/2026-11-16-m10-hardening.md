# M10 — Hardening & First-Run (reviewed by Astra + Argon: `docs/brainstorm/{astra,argon}_m10.md`)

> **For agentic workers:** test-first, do NOT commit, never delete/write outside F:\sound_system, port 8790, tests never write into data/review/. Read AGENTS.md, docs/SPEC.md, start.bat, scripts/setup.ps1, scripts/open-when-ready.ps1, scripts/prefetch_models.py, backend/main.py, backend/core/{settings,capabilities}.py first.

Goal: a non-technical user (EN or AR) can install, start and use the app reliably, offline after setup, without filling C:, and recover from crashes. (Portable packaging for friends = M10b, separate.)

## Must-have tasks
1. **Launcher (`start.bat` + helper `scripts/start.ps1`):** `chcp 65001`, `PYTHONUTF8=1`; validate `SOUND_SYSTEM_PORT` is an integer 1024–65535 before use (never interpolate raw); **single-instance** (if our app already answers on the port → just open the browser; if another program holds it → bilingual message); rebuild `frontend/dist` when any of `frontend/src/**`, `frontend/public/**`, `index.html`, `vite.config.ts`, `tsconfig*.json`, `package.json`, `package-lock.json` is newer than `dist/index.html`; `uv sync` when `uv.lock`/`pyproject.toml` changed; health wait 90 s (antivirus cold start); bilingual EN/AR messages for: port busy, uv/node missing, ffmpeg/ffprobe missing (repair each independently), low disk, root path inside OneDrive or longer than 80 chars (warn).
2. **Keep C: clean:** setup, launcher and the app set `UV_CACHE_DIR`, `npm_config_cache`, `TEMP`, `TMP`, `TMPDIR` to `<root>\data\tmp` (and pip/HF caches already under models/); ffmpeg zip extraction uses `data\tmp`; `scripts/make_review_files.py` temp dirs too. Test: a full pipeline run with Arabic+space paths leaves zero new files in the system %TEMP%.
3. **Models:** one shared downloader (`backend/core/model_download.py`) used by setup and the UI: allowlisted model ids from the manifest, pinned revisions, SHA-256 where known (record measured hashes into the manifest), resumable `.part` + atomic rename, cancel, progress (`model_downloading{model_id,pct}`), `refresh_capabilities()` afterwards. **Fix prefetch: DeepFilterNet3 is currently skipped while returning success** — implement it. Setup prefetches the core set (deepfilternet3, htdemucs, whisper_small, silero bundled); optional models (whisper_turbo, kim_vocal_2) via `setup.ps1 -AllModels` or a UI action ("Download" button on an unavailable step card, with progress + cancel) — `POST /api/models/{id}/download` + SSE progress, Origin-protected. Show measured sizes.
4. **Offline guarantee:** `HF_HUB_OFFLINE=1` + `TRANSFORMERS_OFFLINE=1` in the worker when models are present; test with a socket guard (no non-loopback connections) running Podcast + separate + subtitles end-to-end after prefetch.
5. **Disk safety:** `POST /api/jobs` and `/retry` estimate peak bytes from `duration_s` × channels (48 kHz float32 × 2 intermediates + outputs + video re-encode) and return 507 `insufficient_storage{needed_gb,free_gb}` before queuing; worker handles ENOSPC mid-run as a clear failure (`disk_full`) and cleans `work/`.
6. **Retention:** startup + every 24 h sweep deletes terminal jobs (folders + rows) older than `retention_days` measured from `finished_at`, and media no longer referenced by any retained job; never touches queued/running jobs, active preparations, downloads, or external saved copies (`saved_path`); junction/symlink-safe (resolve + must stay under data/). Settings: retention 1 / 7 / 30 / Never (default 7) + per-job "Keep" (History shows "Expires in N days" / "Kept"). Message codes + EN/AR strings.
7. **Logs & diagnostics:** rotating `data/logs/app.log` (5 MB × 3); worker.log bounded; "Copy diagnostics" in the settings popover → JSON (versions, health, last 50 log lines) with `%USERPROFILE%`, usernames and media filenames redacted.
8. **Security tightening:** production Host/Origin allow-list = exactly `127.0.0.1:<port>` and `localhost:<port>` (remove `testserver`; tests set Host explicitly); keep binding 127.0.0.1.
9. **Recovery:** closing the console window / Ctrl+C / killing the server leaves no orphan worker or ffmpeg (R1 startup kill stays); interrupted jobs show Retry. Test with forced termination.
10. **README.md (EN) + README.ar.md (AR):** quick start (one command), first run (model download sizes), using the app, privacy (all local), troubleshooting (GPU not detected / old driver → CPU works; VC++ runtime missing → link to Microsoft's installer; port busy; models missing; C: full), uninstall (delete the folder), manual update.
11. **Accessibility pass:** keyboard-only full flow, labels, AA contrast, reduced motion — EN and AR (Playwright + axe-core if available offline via npm devDependency).
12. **Performance check:** a 60-min synthetic speech file end-to-end (Podcast) on GPU and CPU: record times in docs/FEASIBILITY.md; UI stays responsive (slow test / script).

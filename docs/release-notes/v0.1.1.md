## Which file do I download?

**Most people need one file.** Ignore the rest.

| Your computer | Download |
|---|---|
| **Windows** (with or without an NVIDIA card) | **`Safa-0.1.1-win-x64-setup.exe`** — small installer; it detects an NVIDIA GPU and downloads the right engine (~1 GB CPU, ~3 GB GPU) with a progress bar |
| Windows, **no internet** on that PC, no NVIDIA | `Safa-0.1.1-win-x64-cpu-offline-setup.exe` — one file, works fully offline |
| Windows, **no internet** on that PC, NVIDIA card | `Safa-0.1.1-win-x64-gpu-offline-setup.exe` **plus every** `…-gpu-offline-setup-N.bin` file, all in the **same folder** |
| Windows, no install (USB / portable) | `Safa-0.1.1-win-x64-cpu-portable.zip` |
| **Mac** (Apple M1/M2/M3/M4) | **`Safa-0.1.1-macos-arm64.dmg`** — open, drag Safa to Applications, first launch: right-click → Open |
| **Linux** Ubuntu / Debian | `Safa-0.1.1-linux-x64-cpu.deb` |
| **Linux** Fedora | `Safa-0.1.1-linux-x64-cpu.rpm` |
| **Linux** other | `Safa-0.1.1-linux-x64.AppImage` |

Everything else (model packs, `.7z` parts, wheel, `SHA256SUMS.txt`, scripts) is for offline, advanced or scripted installs — see the README.

Windows shows "Windows protected your PC" because Safa is not code-signed yet: click **More info → Run anyway**.

## أي ملف أنزّل؟

**معظم الناس يحتاجون ملفاً واحداً فقط.** تجاهل الباقي.

| جهازك | نزّل |
|---|---|
| **ويندوز** (مع بطاقة NVIDIA أو بدونها) | **`Safa-0.1.1-win-x64-setup.exe`** — مثبّت صغير يكتشف بطاقة NVIDIA وينزّل المحرّك المناسب (حوالي 1 غ.ب للمعالج، 3 غ.ب للبطاقة) مع شريط تقدّم |
| ويندوز **بدون إنترنت** على ذلك الجهاز، بدون NVIDIA | `Safa-0.1.1-win-x64-cpu-offline-setup.exe` — ملف واحد يعمل بدون إنترنت |
| ويندوز **بدون إنترنت**، مع بطاقة NVIDIA | `Safa-0.1.1-win-x64-gpu-offline-setup.exe` **مع كل** ملفات `…-gpu-offline-setup-N.bin` في **نفس المجلد** |
| ويندوز بدون تثبيت (محمول) | `Safa-0.1.1-win-x64-cpu-portable.zip` |
| **ماك** (Apple M1/M2/M3/M4) | **`Safa-0.1.1-macos-arm64.dmg`** — افتحه واسحب صفا إلى Applications، وأول مرة: زر يمين ← Open |
| **لينكس** أوبونتو / ديبيان | `Safa-0.1.1-linux-x64-cpu.deb` |
| **لينكس** فيدورا | `Safa-0.1.1-linux-x64-cpu.rpm` |
| **لينكس** غير ذلك | `Safa-0.1.1-linux-x64.AppImage` |

يظهر تحذير "Windows protected your PC" لأن صفا غير موقّع رقمياً بعد: اضغط **More info ← Run anyway**.

## What's new in 0.1.1

- **Fixed: Safa did not open on Windows.** The desktop shortcut's `Safa.exe` crashed instantly when started without a console window (every shortcut launch). It now starts, and any startup problem is shown in a message box.
- **Fixed: "Save as…" didn't save.** Chrome cancelled the save itself after you pressed Save, so no file was written. Safa now opens the Windows Save As window from its own server and copies the file — it works in every browser, keeps the right file type, and "Show in folder" finds the file. "Save all to folder…" works the same way.
- **Fixed:** folder names in Arabic could come back garbled from Safa's folder window.
- **Fixed:** after an update the browser could keep showing the old Safa page; the app page is no longer cached.
- **Fixed:** `start.bat` crashed when it needed to rebuild the interface (`npm` not found).
- **Quieter console:** the harmless "ConnectionResetError [WinError 10054]" traceback (the browser cancelling an audio request) is no longer printed.
- **GPU install ~2 GB smaller on Windows.** The CUDA build of PyTorch already contains NVIDIA's libraries; the duplicate NVIDIA packages (2.7 GB installed) are gone. Whisper subtitles and vocal separation use PyTorch's copy.
- **CPU install smaller.** CPU builds now carry the 11 MB CPU ONNX Runtime instead of the 280 MB GPU edition (~700 MB less on disk).
- **Online installer shows real progress**: step, percentage, size and time left, with a working Cancel — no more frozen-looking window.
- **Online installer deletes its download cache** (several GB) after a successful install.
- **GPU offline installer** stops immediately with the exact file names when its `.bin` parts are missing, instead of an "insert disk" prompt.
- Offline model packs no longer store Hugging Face weights twice.

## A. Security (high)
- **A1 — Host + Origin protection** (Claude + Argon). Today any web page can reach the API: DNS rebinding (attacker domain resolving to 127.0.0.1) gives full read access to recordings/outputs; CORS-simple `POST /api/jobs/{id}/cancel|retry` (no preflight) work cross-site. Fix: middleware in `backend/main.py` that (1) rejects requests whose `Host` is not `127.0.0.1:<port>` / `localhost:<port>` (400 `bad_host`), (2) for POST/PUT/PATCH/DELETE requires `Origin` (or, if absent, `Referer`) to be `http://127.0.0.1:<port>` / `http://localhost:<port>`, else 403 `bad_origin` — runs before any body is read. Requests with neither header (curl, tests) are allowed only when `Host` is valid **and** no `Sec-Fetch-Site: cross-site` header is present. Tests: rebinding Host rejected, cross-site Origin rejected on cancel/retry/upload/delete, same-origin accepted, TestClient default still works.
- **A2 — Upload size/disk bypass** (Argon). `Content-Length: 1` with a huge body skips the disk check. Fix: during streaming, fail with 413 when `written > content_length` (if given), and re-check free space every 256 MB written; still enforce `max_upload_mb`. Test with a lying Content-Length.
- **A3 — ID validation** (Argon). `media_id` / `job_id` path params must match `^[0-9a-f]{32}$` before any filesystem use (404 otherwise). Test with `..%2F..`, `CON`, uppercase.

## B. Correctness (high/medium)
- **B1 — Deleting media with job history crashes** (Claude, confirmed: `IntegrityError: FOREIGN KEY constraint failed` → 500; Argon). Fix: in one transaction delete the media's terminal jobs' `job_files` + `jobs` rows (still 409 if any queued/running), then `media`; then remove `data/jobs/<job>` dirs and the media dir; if `_prepare` is still running for that media, signal it (per-media `threading.Event` registry) and make `_prepare` stop writing into a deleted dir. Tests: delete with completed jobs → 204 and rows/dirs gone; delete during prep → no files recreated.
- **B2 — Cancel vs spawn race** (Argon). Between `next_queued()` → `Popen` and `mark_running`, a cancel marks the job `cancelled` without killing the new worker. Fix: hold the supervisor lock across cancel-check → Popen → `_proc` assignment → `mark_running`; `cancel()` takes the same lock; if `mark_running` affects 0 rows, kill the just-spawned worker. `cancel()` must not block the HTTP request thread for 7 s: return 202 immediately and do the wait/kill on a background thread. Test with a monkeypatched slow `Popen`.
- **B3 — Orphan workers after a crash** (Claude). If the server process dies without its lifespan shutdown (console closed, killed), the worker (own process group) keeps running and holds the GPU while the next server starts a new job. Fix: in `mark_interrupted_on_startup` (or lifespan start) for every `running` row with a `worker_pid`, if that PID is alive and its cmdline contains `backend.worker` and the job id → kill the tree before marking interrupted. Test with a fake long-running child.
- **B4 — SSE thread leak** (Claude). `/api/jobs/{id}/events` uses a sync generator with `time.sleep`; Starlette runs it in the threadpool and it never notices a disconnected client, so every page refresh during a long job pins a thread until the job ends (≈40 refreshes → server hangs). Fix: async generator with `asyncio.sleep(0.25)` and `if await request.is_disconnected(): return`; DB reads via `run_in_threadpool`. Include `files` in every state event (needed by M9). Test: open/close 60 streams on a running job → threadpool not exhausted (a normal GET still answers < 1 s).
- **B5 — "Shorten pauses" math** (Argon). Blocks already include `pad_s`; shorten adds `keep_pause_s/2` on each side → keeps `2·pad + keep_pause` and 0.30–0.45 s pauses are never shortened. Fix: total kept silence per gap = `min(raw_gap, max(2·pad_s, keep_pause_s))`. Tests: exact kept pause on 0.35 s and 3.0 s gaps.
- **B6 — Speed changes video fps** (Claude M4b note + Argon). `fps * speed` output (31.25 / 37.5 / 120 fps). Fix: `setpts=PTS/speed,fps=<source fps>`. Test asserts output fps == source fps and duration == timeline out_duration ± 1 frame.
- **B7 — Snap drift when silence follows trim on video** (Argon). Intersect the snapped timeline with the parent's kept spans before computing input intervals. Test: trim + silence on video → A/V duration equal ± 1 frame and audio length == timeline.
- **B8 — Throttle drops stage completion** (Argon). `update_progress` must never drop a row with `stage_pct >= 1.0`, `message_code`, `warning_code`, or a state change. Test with a < 250 ms op.
- **B9 — Breath clamp fails beside long pauses** (Argon). `detect_breaths` on a ±1 s splice slice computes speech level from the slice; with > ~11 s pauses P85 lands in silence → no breaths. Fix: compute level stats once on the whole file and pass them in. Test with a 15 s pause + breath before speech.
- **B10 — Model gating per selected model** (Claude M7 note + Argon). `separate` requires only the selected model (`htdemucs` or `kim_vocal_2`) + shared metadata JSONs; `subtitles` requires `whisper_small` for fast and `whisper_turbo` for accurate. Op card unavailable only when *no* model for it is present; `resolve()` rejects a param choice whose model is missing with `model_missing{model_id}`. Tests for each combination.
- **B11 — Peaks for non-default streams** (Argon). On-demand `stream_N.wav` decode has no lock and leaves multi-GB WAVs. Fix: per-(media, stream) lock, temp file + atomic rename for peaks, delete `stream_N.wav` afterwards, run in threadpool. Test: two concurrent requests → one decode, no leftover wav.
- **B12 — Failed jobs leave partial outputs; whisper fallback progress** (Argon). On `failed`, clear `output/` (keep `worker.log`); whisper GPU→CPU fallback reports `device="cpu"` and doesn't reset progress backwards. Tests.
